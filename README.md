## 📖 Overview

Welcome to the personal portfolio website of **Vaibhav Rao Nallani**. Built using React, TypeScript, Vite, and Tailwind CSS, this web application features an **exclusive Black & Gold theme** paired with a neo-brutalist aesthetic, interactive terminal assistant, ambient matrix canvas, and structured academic credentials.

> *"To secure a challenging position in the field of Computer Science and Artificial Intelligence & Machine Learning, where I can apply my technical knowledge, programming skills, and problem-solving abilities to contribute to innovative projects, while continuously learning and enhancing my expertise in emerging technologies."* — **Vaibhav Rao Nallani**

## ✨ Key Features

- **⚡ Blazing Fast Performance**: Powered by Vite and React 18 for instant hot module reloading and optimized production bundles.
- **🎨 Luxury Black & Gold Design**: Curated color palette (`#070707` and `#D4AF37`) with brutalist offset borders, glow effects, and high text contrast (> 14:1 contrast ratio).
- **🖥️ Interactive CLI Terminal**: Floating command-line assistant accessible via `Ctrl + K` or mobile button, supporting commands like `help`, `about`, `skills`, `education`, `projects`, `certifications`, and `contact`.
- **🌧️ Ambient Gold Matrix Rain**: Custom HTML5 canvas animation rendering golden streaming code characters.
- **🎓 Academic Qualifications**: Detailed timeline covering undergraduate studies at Kakatiya Institute of Technology & Science (KITS), intermediate education, and high school credentials.
- **💻 Verified Technical Skills**: Focused competencies in **C**, **Java**, and **Object-Oriented Programming (OOP)** concepts.
- **📊 Projects Showcase**: Highlights *Virtual Portfolio Simulation*, *Restaurant Management System*, and *Research on Stock Market*.
- **📜 Certifications & Workshops**: Credential cards for *UI/UX Workshop*, *Stock Market Basics*, and *Digital Marketing*.
- **📱 Fully Responsive**: Optimized layouts across mobile, tablet, and widescreen desktop displays.

## 🚀 Getting Started

### **Prerequisites**
- Node.js (v18+) or Bun (v1.0+)

### **Installation**
```bash
# Clone or open repository
cd Portfolio-main

# Install dependencies
bun install
# or
npm install
```

### **Running Locally**
```bash
# Start development server
bun run dev
# or
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### **Production Build**
```bash
bun run build
# or
npm run build
```
